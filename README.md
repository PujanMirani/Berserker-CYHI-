# 🛠 Hackathon Toolkit

A unified CLI toolkit containing 4 essential developer tools for fast debugging and system management.

## 📦 Requirements & Installation

Requires **Python 3.8+**.

```bash
# Clone repository
git clone <repo-url>
cd hackathon-toolkit

# Install dependencies
pip install -r requirements.txt
```

## 🚀 Usage

Run the main menu shell:

```bash
python main.py
```

## 🛠 Included Tools

1. **🔍 digger**: Correlate logs across multiple microservices by timestamp and shared transaction identifiers (order IDs, UUIDs, request IDs).
2. **🔫 portkiller**: Instantly find and terminate any process blocking a local port (`psutil`).
3. **🔧 tool3**: Teammate 3 Tool.
4. **📦 tool4**: Teammate 4 Tool.
